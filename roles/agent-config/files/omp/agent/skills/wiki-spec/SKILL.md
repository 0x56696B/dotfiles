Trigger before you add, rename, or remove a skill, a page type, a field, a folder, or a workflow gate in the wiki system.

Read `skill://wiki-spec/SPEC.md` first. It is the full contract: decisions, architecture, page types, workflows, gates, and setup.
Read `vault://wiki/schema.md` next. It is the field-level contract for every page type. Keep the two files in agreement.
